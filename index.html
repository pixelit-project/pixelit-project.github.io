This documentation targets the stable PixelIt 2.6.0 release (opens new window).

  • Pixel Creator

# Supported hardware

Install PixelIt on a supported prebuilt clock or build a DIY display. Optional sensors, buttons and a DFPlayer Mini extend its capabilities.

# Prebuilt Hardware

  • Ulanzi TC001 Pixel Clock (opens new window)

# DIY Hardware

  • MCU
    • Generic ESP32 and D1 mini32
    • Wemos D1 mini
    • NodeMCU v2
    • Generic ESP8266
  • Matrix
    • Pixelmatrix (8x32)
    • Pixelmatrix (CJMCU)(4x 8x8)
    • MicroMatrix by foorschtbar (4x 8x8)
  • Extensions
    • LDR GL5516
    • DHT22
    • BME280
    • BME680
    • DFPlayer Mini
    • Touch Buttons

# Getting started

  • Start with the hardware and check out the parts list.
  • Then you can flash the firmware and configure the matrix in the webinterface.
  • Finally, send screens through the API or use Node-RED (recommended) or ioBroker to create and send your own screens to your PixelIt.

# Support

Any problems? Checkout the Troubleshooting section. If you still need help or just connect to other PixelIt users, check out the project forum or the Telegram and Discord groups.
